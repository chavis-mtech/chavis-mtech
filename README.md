## 🚀 Featured Project: Digital Mill Lab

A **concept demo** of an industrial-intelligence layer for a *fictional* palm oil mill: executive KPIs, equipment health, maintenance work orders, logistics queues, energy, traceability, scenario and ROI simulation, and a grounded AI Copilot.

> Independent portfolio project. **All data is synthetic.** It is not connected to any real system and is not an official system of any company. I designed and directed the build with AI coding agents under a written specification and an independent verification log.

[![Live Demo](https://img.shields.io/badge/Live_Demo-digital--mill--lab--web.vercel.app-000000?style=flat-square&logo=vercel&logoColor=white)](https://digital-mill-lab-web.vercel.app)
[![Source Code](https://img.shields.io/badge/Source_Code-chavis--mtech%2Fdigital--mill--lab-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/chavis-mtech/digital-mill-lab)

- Deterministic synthetic dataset (120 days) with mass-balance checks
- Equipment-health anomaly detection and 8 machine-learning models evaluated against simple baselines. Several do **not** beat their baseline, and the demo reports that as measured
- Maintenance work orders in which a person confirms every step; each change is written to a hash-chained audit log
- A Copilot that answers only from approved tools and refuses to guess
- Next.js, FastAPI, scikit-learn, Playwright (20 end-to-end scenarios), Docker, GitHub Actions
